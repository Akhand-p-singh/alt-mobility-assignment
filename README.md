# 🔥 Alt-Mobility Assignment


# 📊 Project Overview
The analysis focuses on using the provided datasets to understand order fulfillment, customer behavior, payment success rates, and customer retention trends.


📊 Datasets
  1. payments.csv - Contains payment status data.
  2. customer_orders.csv - Contains order details including customer info.

Dataset were ready to go. Imported the dataset into Microsoft SQL Server through import flat file.


# 🧠 Tasks & Approach

✅ Order and Sales Analysis

  - Order Status with total order and percentage
  - Yearly trend of total orders and sales
 - Average order amount year by year


✅ Customer Analysis: 

  - new customer, returning customer by Month and Year
  - customer with more than 1 order
  - Customer with only 1 order


✅ Payment Status Analysis: 

  - Payment Status
  - Payment Method Distribution and Payment Status with Payment Success Rates
  - Monthly failed vs. successful payments

✅ Comprehensive Report:

  - Comprehensive Report


# 📌 Recommendations


  1 Streamline payment gateways, ensuring compatibility with services like PayPal and credit cards. 
  2 Provide first-time customers with limited-time offers or exclusive rewards to inspire them to return.
  3 Company loosing customer over failed payment try to make it right.
  4 Improve coordination between shipping and delivery systems.
  5 Invest in additional stock and marketing efforts during peak season
